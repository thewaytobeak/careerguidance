# Три грани анализа: Путь аналитика

Интерактивная профориентационная новелла для студентов на движке **Ren'Py**, помогающая определить, какой вид аналитика подходит игроку больше всего: **бизнес-аналитик**, **системный аналитик**, **аналитик данных** или **универсальный аналитик**.

## О проекте

Игрок оказывается на месте нового сотрудника отдела аналитики и вместе с наставником Алексеем и коллегами — Дарьей (бизнес-аналитик), Семёном (системный аналитик) и Еленой (аналитик данных) — проходит через реальный кейс: автоматизацию складского учёта для крупного клиента.

На протяжении истории игрок 7 раз сталкивается с выбором, как поступить в той или иной рабочей ситуации (сбор требований, оценка объёма данных, документация, критерии приёмки, изменение требований клиента, анализ данных, подведение итогов). Каждый выбор добавляет очки одному из четырёх направлений:

- **Бизнес-анализ** — работа с клиентом, выявление потребностей, бизнес-ценность
- **Системный анализ** — архитектура, интеграции, требования к API
- **Анализ данных** — метрики, прогнозы, дашборды
- **Универсальность** — сбалансированный, комплексный подход

По итогам всех выборов игра определяет, к какому направлению у игрока больше склонности, и показывает персональный результат с рекомендацией пути развития.

## Структура проекта

```
SoloPlayer-1.0-pc/
├── SoloPlayer.exe / .sh / .py   # запуск игры (Windows / Linux-macOS / Python)
├── renpy/                       # ядро движка Ren'Py
├── lib/                         # бинарные файлы движка под платформу
└── game/
    ├── script.rpy                # основной сценарий: сюжет, диалоги, ветвление, подсчёт очков
    ├── screens.rpy                # экраны интерфейса (меню, настройки, сохранения и т.д.)
    ├── options.rpy                # настройки игры (название — "Solo Player", версия 1.0)
    ├── gui.rpy                    # тема оформления интерфейса
    ├── images/                    # иллюстрации: персонажи, локации, финальный экран
    │   ├── alex.png, daria.png, semen.png, elena.png   — персонажи
    │   ├── building.png, office.png, workplace.png,
    │   │   whiteboard.png, development.png, problem.png,
    │   │   dashboard.png, presentation.png              — локации/сцены
    │   └── analyst_end.png                              — финальный экран результата

    └── libs/, cache/              # служебные файлы и кэш компиляции
```

## Игровая механика

1. Вступление — знакомство с наставником и выбор первичного интереса к аналитике.
2. Шесть рабочих сценариев по ходу проекта (интервью с клиентом, оценка данных, документация, критерии приёмки, изменение требований, работа с инсайтами).
3. Подсчёт очков по четырём направлениям (`business_skill`, `system_skill`, `data_skill`, `balance`).
4. Финал: определение доминирующего направления и персонализированное заключение о профессиональном пути игрока.

## Запуск

- **Windows:** запустить `SoloPlayer.exe`.
- **Linux/macOS:** запустить `./SoloPlayer.sh`.
- **Через Python:** `SoloPlayer.py` (загрузчик `renpy.bootstrap`, требует наличия папок `renpy/` и `lib/`, которые уже включены в архив).

## Технические детали
